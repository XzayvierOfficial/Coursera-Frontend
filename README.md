# Xzayvier Ford-Smith — Portfolio Website

A responsive portfolio built with plain HTML, CSS, and JavaScript for the Coursera Introduction to Web Development final project.

## Features
- Semantic HTML, accessible navigation, keyboard focus states, skip link, alternative text for graphic illustrations and live status feedback.
- Responsive CSS for desktop, tablet and mobile.
- JavaScript mobile navigation, theme toggle with optional persistence, project category filtering, and copy-link interaction.

## Run locally
Open `index.html` in any modern browser. No dependencies or build command are needed.

## Publish to GitHub Pages
1. Create a public repository, e.g. `portfolio-website`.
2. Upload all files to the repository root and commit.
3. Go to **Settings → Pages → Build and deployment**.
4. Under Source choose **Deploy from a branch**, then select **main** and **/(root)** and save.
5. Your site should become available at `https://YOUR-USERNAME.github.io/portfolio-website/` once GitHub completes deployment.
